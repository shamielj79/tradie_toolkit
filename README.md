# 🔧 Tradie Toolkit

A mobile-friendly collection of practical calculators and business tools designed for tradespeople, contractors, builders, painters, tilers, plumbers, and other professionals.

## About

**Tradie Toolkit** is a lightweight web application developed by **RS Web Solutions**.

The app is designed to provide quick, practical calculations directly from a mobile device without requiring an account, database, or complicated setup.

All core calculations are performed locally in the browser.

## Features

### Construction Tools

* 📐 Area Calculator
* 🧱 Concrete Calculator
* ⬜ Tile Calculator
* 🎨 Paint Calculator
* 🧱 Brick Calculator
* 🏠 Plaster Calculator

### Business Tools

* 💰 Markup & Margin Calculator
* 🧾 VAT Calculator
* ⏱️ Labour Rate Calculator
* 📋 Quote Builder

### Quote Management

* 💾 Save quotes locally
* View saved quotes
* Reopen saved quotes
* Delete saved quotes
* Share quotes using the device's sharing functionality
* Print quotes or save them as PDF

## Technology

Tradie Toolkit is built as a standalone HTML5 web application using:

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
* Native Web Share API where supported
* Browser printing / PDF functionality

The application does not require:

* A database
* User accounts
* External APIs
* External JavaScript libraries
* External fonts
* Server-side processing

## Privacy

Tradie Toolkit does not require users to create an account or submit personal information to use the calculators.

Saved quotes are stored locally on the user's device using browser storage. RS Web Solutions does not receive or automatically transmit the locally saved quote information through the application.

Users should avoid entering sensitive personal information into quotes unless necessary.

## Disclaimer

The calculators provide estimates intended for general planning and convenience.

Material quantities can vary depending on product specifications, application methods, site conditions, wastage, local building practices, and manufacturer recommendations.

Always verify calculations, quantities, material specifications, pricing, and applicable regulations before purchasing materials or carrying out construction work.
